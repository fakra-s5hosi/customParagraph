# jankenpo-socket

## Demonstração

Há uma gravação mostrando duas abas jogando uma contra a outra em tempo real.

## Instalação

Depois de instalar o runtime e o gerenciador de pacotes pelo site oficial, rode na pasta do projeto:

```
> npm install
```

## Execução

```
> node index.js
```

Depois disso, abra duas abas apontando para o endereço local que aparece no terminal — uma escolhe pedra e a outra responde.
